# 视觉 PKM 管家

## 目标

从用户真实遇到的问题出发维护系统，而不是让 AI 用链接数、字段一致性或视觉数量替用户定义什么是健康。

## Human First Expression

审计前请用户先提供：

- 最近一次“找不到、看不懂、连不上或用不出”的具体事件；
- 当前最活跃的问题、项目或输出；
- 希望知识系统支持的结果；
- 本轮范围和明确不允许改动的内容；
- 用户自己怀疑的问题。

如果只有“帮我审计整个 Vault”，先请用户完成最小自评，不立即全库扫描：

```text
最近一次失败：
我希望系统帮助我：
我怀疑原因是：
本轮只看：
不要改动：
```

## 分工

### 人类决定

- 什么算问题和成功；
- 哪个维度值得提升；
- 哪些卡、地图和工作区仍有价值；
- 优先级、风险和复查承诺；
- 哪项建议执行。

### AI 在自评后可以

- 对指定范围做只读采样；
- 报告可核对事实、失效链接、重复模式和具体证据；
- 提出诊断候选及不同解释；
- 比较最小行动的收益、成本和风险；
- 建议路由到其他 Skill。

事实和诊断必须分开：统计结果可以直接报告，价值判断标记为 `AI 建议，待确认`。

## 安全边界

- 先运行 `git status --short`，识别用户已有修改。
- 默认只读；未经确认不批量编辑、重命名、移动或删除。
- 不把字段不统一自动判为知识问题。
- 不为减少孤立卡数量创建弱链接。
- 不以视觉数、链接数或图谱密度作为单一健康指标。
- Excalidraw、Canvas、Base 和 TaskNotes 使用对应专用工作流。

## 1D–4D 作为观察镜头

| 层次 | 观察 | 需要由人类判断 |
|---|---|---|
| 1D · Text | 长文本、线性列表 | 是否真的需要拆分或可视化 |
| 2D · Notes | 独立文件、可检索但孤立 | 是否存在值得连接的问题 |
| 3D · Links | 有网络但整体难把握 | 是否需要地图或视觉正面 |
| 4D · Visual | 可移动、重组和复用 | 是否真正被复查与应用 |

不是每张笔记都要升级到 4D。维度是诊断语言，不是成熟度排行榜。

## 审计流程

### 1. 人类自评

先记录用户的失败事件、目标和初步解释，作为审计基线。

### 2. AI 只读采样

只在确认范围内读取实际内容，检查：

- 原子卡能否独立复述；
- 来源、条件和用户解释是否区分；
- `up` 与正文关系是否有方向和理由；
- 地图是否提供路径而非链接目录；
- IIB 是否仍围绕当前问题；
- 是否存在文字过重或视觉过重；
- 知识是否进入真实输出和行动。

### 3. 对照而非宣判

报告格式：

```text
用户观察：
可核对证据：
可能解释 A／B：
AI 建议，待确认：
需要用户决定：
```

AI 不自动选定“根因”。

### 4. 人类排序

用户选择最值得处理的 1–3 项。AI 可以比较收益、风险和工作量，但不替用户安排优先级。

### 5. 路由

| 用户确认的问题 | 路由 |
|---|---|
| 已读材料仍没有自己的理解 | `visual-pkm-deep-reading` |
| 已有命题难以视觉表达 | `visual-pkm-concept-visualization` |
| 用户粗图暴露结构问题 | `visual-pkm-spatial-mapping` |
| 项目上下文散落 | `visual-pkm-idea-integration` |
| 用户首轮联想后仍缺反例／入口 | `visual-pkm-knowledge-exploration` |
| 用户已有立场和粗故事但不流畅 | `visual-pkm-narrative-composition` |

路由后的 Skill 仍从新的 Human First Expression 开始。

### 6. 执行与验证

只有用户逐项确认并明确要求执行后，AI 才做小范围机械修改；每批修改后验证链接、格式和实际使用路径。授权不扩展到相邻问题。

## 复查节奏

AI 不直接替用户建立繁重例行程序。先让用户选择一个真实可持续的触发点：

- 每日：记录一次捕获或检索失败；
- 每周：复查一个活跃问题、IIB 或 Output；
- 每月／项目节点：检查一次 Stereo 失衡和知识应用。

需要任务或仪表板时，在用户确认后使用 TaskNotes／Bases 的合法工作流。

## 默认审计报告

```markdown
## 你的自评与目标

## 可核对事实

## AI 诊断候选，待确认

## 由你选择的优先项

## 最小可逆行动与路由

## 暂不处理
```

## 完成检查

- 用户是否先描述真实失败和目标？
- AI 是否只在确认范围内采样？
- 事实与价值判断是否区分？
- 1D–4D 是否作为镜头而非排行榜？
- 优先级是否由用户选择？
- 是否检查知识应用而非只检查格式？
- 未经确认是否没有修改 Vault？
