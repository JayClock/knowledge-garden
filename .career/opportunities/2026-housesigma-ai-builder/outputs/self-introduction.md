## 90～120 秒版本

面试官你好，我叫钟杰，有五年以上开发经验，主要使用 React 和 TypeScript，也用 NestJS、PostgreSQL 和 Prisma 做过服务与数据层开发。我定位是全栈偏前端的平台工程师，习惯先把业务问题和验收条件说清楚，再通过实现和运行反馈检查结果。

在鼎歆，我设计并实现了领域建模平台，也设计了一套实际使用的 Skill 工作流。人先提供真实业务约定，AI 帮助逐项澄清权责和异常场景。讨论结果保留来源，经人工审核后，再用于 API 和测试数据生成。

在易校，多端各自维护权限和状态规则容易漂移。我负责 HATEOAS SDK 与 React 消费层，和后端协同把资源关系、动作模板接入业务。我也用 AI 辅助生成保存和发布的回归测试，检查增量改造的兼容性，通用 SDK 后续发布成了 npm 包。

执行侧，我负责低代码工作流的协议、可视化编辑器、变量与公式编辑器，以及 TypeScript 引擎，处理拓扑调度和条件分支，并接入后端 SSE 展示执行反馈。

另外，我独立负责前端监控 SDK 的采集与上报，从排障需要倒推事件设计，通过多框架适配、本地队列、失败重试和 Sourcemap 提供运行证据。

这些经历贯穿的是同一件事：把问题定义清楚，让 AI 和软件按明确约束参与，再用证据验收，并把有效机制沉淀为可复用的工作方式。
