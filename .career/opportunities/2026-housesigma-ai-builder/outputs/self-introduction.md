## 90～120 秒版本

面试官你好，我叫钟杰，有五年以上开发经验，主要使用 React、TypeScript，也用 NestJS、PostgreSQL、Prisma 开发过服务和数据层。我定位全栈偏前端，习惯先明确业务问题和验收条件，再用实现和运行反馈检查结果。

在鼎歆，我负责 AI 辅助领域建模与 API 设计平台的流程与核心能力，用双层循环 Harness 澄清真实约定、权责和异常。AI 增量维护本地模型；经过一致性、范围检查与人工确认，再设计 API、生成文档和静态测试向量。

在易校，复杂权限需要前后端重复维护判断逻辑。我负责 HATEOAS SDK 与 React 消费层，和后端协同把资源关系、动作模板接入业务。我也用 AI 辅助生成保存和发布的回归测试，检查增量改造的兼容性，通用 SDK 后续发布成了 npm 包。

执行侧，我负责普通业务工作流的协议、可视化编辑器、变量与公式编辑器，以及 TypeScript 引擎，处理拓扑调度和条件分支，并实现 SSE 服务端推送与前端执行反馈。

运行诊断侧，我负责监控 SDK 和数据采集后端，以统一事件连接多框架采集、队列上报、NestJS 接收、Kafka 处理和 ClickHouse 存储，并接入 Sourcemap 定位源码。系统响应性能提升了 50%。

这些项目通过 Nx + pnpm 管理多包工程。我的主线是定义问题，让 AI 与软件按明确约束参与，再用证据验收，并沉淀可复用的工作方式。
