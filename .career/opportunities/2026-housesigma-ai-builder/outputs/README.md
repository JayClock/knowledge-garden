# HouseSigma AI Builder｜职业投递包

本包使用职业经历中的项目 2～5，独立保存本次岗位材料，不覆盖其他岗位包或 Vault 通用讲稿。

## 文件导航

| 文件 | 用途 |
|---|---|
| [岗位简历](resume.md) | 对外书面简历，保留四个项目 |
| [岗位自我介绍](self-introduction.md) | 90～120 秒开场，含独立提取词 |
| [项目口述底稿](interview-script.md) | 四个项目的约 2 分钟版本与提取词 |
| [面试练习计划](interview-plan.md) | 唯一当前任务、项目追问与练习方法 |
| [岗位映射](opportunity-brief.md) | 内部选材依据与待补证据 |
| [招聘描述](job-description.md) | 用户提供的 JD，清理 HTML 后保存 |

这是 Markdown 投递准备包；本轮未生成 Word 或 PDF。岗位映射、练习计划和依赖记录属于内部材料，不随简历发给招聘方。

## 开始练习

先不看全文，尝试一次 90～120 秒岗位自我介绍：

> 请介绍一下你自己，并说明哪些经历能支持你担任 AI Builder。

自行计时，发原始转写和实际用时。收到回答后再选择一个主要调整；需要时才打开提取词或参考稿。

## 记录与隐私

当前仅保存投递与练习材料，尚未保存本岗位练习表现或登记真实投递。用户明确授权后才追加练习日志。

本包位于 Git 根目录 `.career/`，简历包含求职联系方式。分享时选择具体对外文件，不整包公开。本包不写入 Vault 发布正文；提交或分享整个 Git 仓库时，仍需另行检查访问权限。
