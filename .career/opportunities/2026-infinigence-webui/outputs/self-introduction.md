## 90～120 秒版本

面试官你好，我叫钟杰，有五年以上软件开发经验，主要用 React 和 TypeScript，做过低代码平台、复杂编辑器和内部研发工具。我比较擅长把交互、数据结构和接口衔接起来，再完成构建交付。

最近我独立做了一款类 Figma 的 AI 设计工具，用 Canvas 实现图层、属性面板、拖拽和布局编辑。AI 和编辑器共用一份设计 DSL，生成后做校验和局部修复。我也完成了 Electron 打包和安全加固，交付了 macOS、Windows 安装包。

之前做低代码工作流，我负责流程画布、变量和公式编辑，也实现了执行引擎。公式先解析成 AST，保存时检查，运行时求值，再通过 SSE 和日志界面反馈执行情况。

针对复杂权限下前后端重复维护判断的问题，我和后端一起设计资源关系与动作契约，编写 TypeScript SDK 和 React Hooks，让页面按契约展示入口、生成动态表单，并把通用能力发布为 npm 包。

我还做过监控 SDK 和数据采集后端，包含 React、Vue 的框架适配、性能与异常采集、批量上报和 Sourcemap 定位，方便开发同事排查运行问题。

工程上，我用 Nx 加 pnpm 管理项目，配置过检查、测试、构建流水线，也写过多阶段 Dockerfile。希望继续做产品和内部系统的前端开发，把交互需求落实成可维护、可验证的界面。
