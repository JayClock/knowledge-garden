# 北京无问芯穹科技｜WebUI 前端岗位

来源：用户本轮粘贴的招聘信息。招聘联系人：汪女士（HR）。原文未给出正式岗位名称，材料以“前端工程师（WebUI）”归纳；未给出工作地点和截止日期。

## 职位描述

CSS　JavaScript　HTML5

要有 Vue 经验，better to have Vue 3，感谢。

负责公司正式产品、原型产品或内部系统的 WebUI 开发。

1. 设计、开发和维护前端系统，确保产品的高质量、高性能和高可靠性；
2. 与产品和设计团队紧密合作，理解业务需求，制定最佳的技术方案；
3. 优化前端系统的性能和用户体验，确保产品能够在不同平台和设备上良好运行；
4. 负责前端代码的版本管理和部署工作；
5. 主动关注技术行业的最新趋势，探索新技术并将其应用于公司的产品和流程中。

## 职位要求

1. 本科及以上学历，3–5 年工作经验。
2. 精通 HTML / JS / CSS，熟练使用 UI 库（AntD、Element、MUI 等）。
3. 熟练掌握主流框架，如 React、Vue。了解 Electron 优先。
4. 熟悉前端的安全防护、性能优化等相关问题。
5. 了解 webpack、Vite 配置，能独立完成项目。
6. 有较好的交互设计 sense，能够完成“原型草图”到“成品”的完整过程。
7. 热爱技术，钻研本质，终身学习，在工作中不被经验束缚，从第一性原理出发思考问题。
