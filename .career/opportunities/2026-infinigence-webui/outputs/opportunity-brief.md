# 岗位选材说明｜无问芯穹 WebUI

本说明用于自己选材和沟通，不随简历一并发送。

## 本轮表达主线

**能完成复杂交互界面、接口消费和工程交付的前端工程师。** React / TypeScript 是基本盘，复杂编辑器与监控是具体加分项。简历不以全栈或领域方法论开场，服务端内容只用于解释完整交付能力。

## 核心要求与证据

| 岗位关注 | 已有依据 | 选材处理 |
| --- | --- | --- |
| Vue 经验，Vue 3 更佳 | 监控 SDK 的 Vue 适配包与平台 Vue 模块接入 | 明确写成 SDK 适配；不替换为 Vue 3 业务开发经历 |
| 原型、正式产品、内部系统的 WebUI | React Flow、Tiptap、公式和动态表单 | 工作流放在第一页面，突出实际交互和实现 |

| 构建、版本与交付 | Nx + pnpm、Vite、GitHub Actions 检查测试构建、npm tag 发布、多阶段 Dockerfile | 不扩展为生产自动部署；CI 和 Docker 不自行绑定到某家公司 |

## 项目顺序及来源

1. **低代码工作流引擎**：画布、变量、公式、执行和反馈。回读《AI 工作流引擎编辑器与执行器架构设计与实践》的数据协议、编辑器及执行器机制；实际经历按普通业务工作流和当前职责表达。
2. **HATEOAS SDK**：资源与动作、动态表单、缓存、测试和发布。依据 `content/Knowledge/Sources/hateoas-ts/README.md`、`RELEASE.md`、当前项目介绍及已确认的契约消费实现选材。
3. **前端监控 SDK 与数据采集**：Vue 框架适配、性能与异常、队列和源码定位。回读《企业级监控平台全栈架构设计与实践面试专项突击》的架构、简历描述及专项问题；本次只选已确认的 SDK 与数据后端。

## 沟通前需要核对

- **Vue 是主要匹配风险**：招聘补充明确“要有 Vue 经验”。当前能证明 SDK 适配，仍需向招聘方确认是否接受 React 为主、具备 Vue 接入经验的背景。如本人还有 Vue 3 页面、Composition API 或完整业务交付经历，应先补充核对，再更新材料。
- UI 库已有 Radix UI、样式已有 Tailwind CSS；AntD / Element / MUI、webpack 配置和 Web 安全治理暂无独立确认。
- 当前现居上海；公司名称含“北京”不等于岗位工作地点，面试前确认办公地点、出勤方式及异地安排。
- 正式职位名称、薪资范围和招聘截止日期未提供。岗位材料采用“前端工程师”，不补写资级、薪资或到岗承诺。
