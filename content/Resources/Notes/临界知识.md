在核武器中，有一个临界质量的概念。如果要引爆，需要满足以下条件：
1. 必须得是铀 235
2. 必须达到一定质量
那么在知识体系的构建中，为了达到高效的跨界学习能力，就需要探查世界的抽象本质，在互联网技术中，临界知识分为以下三类：
## 编程语言
我选择 C、C++ 和 Java，选择他们的原因是，C、C++ 和 Java 都是工业级语言。为什么说它们是工业级的呢？主要是，C 和 C++ 语言规范都由 ISO 标准化过，而且都有工业界厂商组成的标准化委员会来制定工业标准。次要原因是，它们已经在业界应用于许多重要的生产环境中。
大概的学习逻辑：《java 核心技术》中学习 java 基础知识 -> 通过书中的 c 语言相关注释去学习 c -> c 和 c++ 对比 -> 涉及到硬件相关的，再去读操作系统相关的书籍。
## 理论学科
编程领域，算法、数据结构、网络模型、计算机原理等
## 系统知识
操作系统，一个是网络系统，还有一个是数据库系统。它们分别代表着计算机基础构架的三大件——计算、存储、网络。
