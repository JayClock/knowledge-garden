# Inbox 收集

在阅读、学习、工作过程中，所获取到的一切信息，以及内心产生的灵感与想法，可以先凭直觉，或者说是最先触动到自己的内容，都先全部放进收集箱中，避免打断心流状态。

# Note 概念

每天找出一个固定的时间段，去整理信息箱中的内容，如果对其中某个具体概念、知识点感兴趣，就去主动学习和阅读。补充成一则更完善的笔记，在把它放入 note 文件夹下。我们称之为概念笔记。

# Knowledge 主题

当概念笔记越来越多时，看看有没有哪些概念之间存在内在的逻辑联系。借助主题目录，把相关的概念笔记统筹起来。这时的主题笔记，对作者来说，便是“关于这个话题，我都知道什么”

# Project 项目

当我们在工作和生活中需要完成一个任务，或者开启一个项目时，就可以新建一个项目笔记。这样的好处有以下 2 点

- 作为一个总控台，帮助我们从已知的概念与主题笔记中获取信息
- 作为一个输出方，帮助我们把项目总的经验与复盘，整合到概念与主题里面
