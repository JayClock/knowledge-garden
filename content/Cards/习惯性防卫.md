# 第一步：总结
这个知识点大概讲了什么？用自己的话去提炼、表述，不要照搬原文
# 第二步：联系
这个知识点可以和其他哪些知识点联系起来？试着去引用已有的其它记录。
# 第三步：举例子。
我能想到哪些跟它相关的生活实践？列出能想到的例子。
# 第四步：写启发
它能给我什么启发，如何知道我的生活实践？写下你觉得能用在实践中的想法。
# 第五步：记出处

记下我做后看到它的出处，以被将来查询溯源。如果对第一步的总结描述不够有把握，直接引用原文。

一种常见且人人都会有的一种心理现象。当我们感受到自己的观点、尊严可能会受到挑战的时候，我们的第一反应不是思考对方的挑战和质疑是否合理，而是“有人赶反对我，和他干！”。这时候，我们的习惯性访问就产生了。

平时在公司开会时，同事之间观点不同的时候，有些人还没听完对方的意见，就急着反驳。这个反驳的主要目的是争论自己的结论是深思熟虑有道理的。很多时候，大家争执了半天才发现，讨论的都不是一个问题，只不过是因为在讨论中觉得自己受到威胁了，就赶紧开始反驳了。
