纯函数（Pure Function）的定义和意义是什么？

---

1. 函数无论被调用多少次，只要参数相同，返回值就一定相同，这一过程不受外部状态或者 IO 操作的影响
2. 函数被调用时不会产生**副作用（Side Effect）**，即不会修改传入的引用参数，也不会修改外部状态，不会触发 IO 操作，也不会调用其他会产生副作用的函数。

比如下面的 js 代码就是一个最简单的纯函数，对于给定的 `a` 和 `b`，返回值永远是两者之和

```js
const func = (a, b) => {
  return a + b;
};
```
