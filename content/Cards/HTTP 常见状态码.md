| 状态码分类 | 描述      | 常见状态码 | 描述                         |
| ----- | ------- | ----- | -------------------------- |
| 1xx   | 服务器收到请求 |       |                            |
| 2xx   | 请求成功    | 200   | 请求成功，请求在服务端被正确处理           |
| 3xx   | 重定向     | 301   | 永久重定向（配合 location，浏览器自动处理） |
|       |         | 302   | 临时重定向（配合 location，浏览器自动处理） |
|       |         | 304   | 资源未被修改                     |
| 4xx   | 客户端错误   | 403   | 没有权限                       |
|       |         | 404   | 资源未找到                      |
| 5xx   | 服务端错误   | 500   | 服务器错误                      |
|       |         | 504   | 网关超时                       |
