# React Fiber 将渐进式思想推进到 UI 调度层

React Fiber 把 UI 渲染拆成可中断、可恢复、可排序的工作单元，使渐进式思想从资源加载和页面呈现进一步进入运行时调度层。

## 为什么重要

在复杂交互应用中，问题不只是资源能否渐进加载，还包括 UI 更新能否避免长时间阻塞主线程。Fiber 让 React 可以把一次更新拆开，优先处理更紧急的用户反馈。

## 核心内容 / 成立机制

早期同步协调模型倾向于“一次更新算到底”。如果组件树很大，渲染任务会长时间占用主线程，造成输入卡顿和页面无响应。

Fiber 的关键变化是：

- 把渲染工作拆成更小的单元；
- 允许工作被中断、恢复和丢弃；
- 为不同更新分配优先级；
- 让 Suspense、useTransition 等并发特性可以表达“哪些更新可以等待”。

因此，Fiber 不是简单地让渲染异步，而是让 UI 更新具备渐进推进和优先级调度的能力。
