# Web 的超媒体模型天然支持渐进式集成

Web 的超媒体模型让客户端可以从一份 HTML 或资源表示出发，逐步发现链接、表单、脚本、样式和后续操作，因此天然支持渐进式集成。

## 为什么重要

这说明渐进式不是现代框架后来发明的优化技巧，而是 Web 平台一开始就具备的结构性能力。

## 核心内容 / 成立机制

HTML 不是只描述静态内容，它还声明了后续能力：

- `<link>` 让浏览器发现样式、预加载资源和相关文档。
- `<script>` 让页面在基础内容之外获得行为增强。
- `<a>` 和表单让用户发现下一步操作。
- 超媒体 API 通过链接和操作描述让客户端发现当前状态下可执行的动作。

这些机制共同形成一种模式：客户端不需要预先掌握全部流程，而是从当前资源中逐步发现下一步能力。

## 应用要点

- 渐进增强是在页面层面对超媒体模型的延续。
- HATEOAS 是在 API 层面对超媒体模型的延续。
- 动态权限可以通过“当前响应中有哪些可用操作”来减少前端硬编码。
