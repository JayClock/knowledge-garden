# 概念可视化

> [!abstract] 核心观点
> **概念可视化不是给词语配一张图，而是让图像成为检验和重塑理解的原型。** 一张图先选择一个核心解释，再用符号、空间关系与反馈把抽象概念变得可见、可测试。

概念视觉不是装饰，也不是关键词与图标的一一配对。它先把复杂内容收窄为**一句尖锐、具体的核心信息**，再选择与概念关系相匹配的视觉结构，让草图暴露矛盾、缺口与隐藏假设。

它把[[Knowledge/Notes/乐高式思考|乐高式思考]]的模块化约束应用到单个概念：视觉可以反复拆解、替换和重组，但每次仍只检验一个核心解释。

## 七步循环

| 步骤         | 要做什么                           | 判断标准          |
| ---------- | ------------------------------ | ------------- |
| 1 · 核心信息   | 用“表层／深层”收窄到一个解释                | 能否写成一句话？      |
| 2 · 联想发散   | 从 3–5 个关键词扩展符号、反义词、隐喻和双关       | 是否越过第一个陈词滥调？  |
| 3 · 选择框架   | 在对比、隐喻、过程、单图、场景中选择             | 视觉结构是否匹配概念结构？ |
| 4 · 复用词库   | 先搜索[[Knowledge/Maps/Icon 索引\|个人图标库]]，再叠加、替换和重组 | 是否复用了熟悉组件？    |
| 5 · ETC 草图 | Express → Test → Cycle，先画五分钟版本 | 还能删掉什么？       |
| 6 · 反馈校准   | 做第一眼、延迟和去文字测试                  | 图像能否先于解释说话？   |
| 7 · 刻意练习   | 重复整套过程，而不是重复同一张图               | 是否产生了不同解释？    |

> [!tip] 不是阶梯，而是循环
> 草图可能迫使你重写核心信息、换一个视觉框架，甚至重新发散联想。回到前一步不是失败，而是理解正在变清楚。

## ETC 与反馈

- **Express**：快速放下想法，不润色。
- **Test**：检查主旨、图意和可删细节。
- **Cycle**：强化重点、清除杂讯，必要时重新开始。
- **反馈测试**：第一眼看见什么？一小时后还清楚吗？去掉文字后仍成立吗？
