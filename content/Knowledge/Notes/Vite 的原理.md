Vite 为什么比 Webpack 在开发环境下快的多？它的原理是什么

---
Webpack 在启动时，必须从导入路径解析出完整的模块以来。项目越庞大，这个初始打包过程就越耗时。

Vite 启动时直接从 index.html 中的 Main 文件中，解析 import 语句。然后按需发起对 Import 导入模块的 Http 请求。vite 会拦截这些请求，按需转译成浏览器可识别的 Js 形式。

这种方式带来的好处是，应用的启动时间不再与项目的大小正相关。当热更新时，vite 只需要让被修改的模块实效，并精确地通知浏览器重新请求这一个模块即可，而不是重新完整编译整个项目
