# 现代前端框架是在恢复 Web 的渐进式本质

SSR、SSG、流式 SSR、选择性注水和 React Server Components 并不是对 SPA 的简单性能优化，而是在把内容优先、按需交互、服务端协作这些 Web 原生渐进原则重新引入框架设计。

## 为什么重要

这能解释为什么现代前端框架越来越重视服务端渲染、部分注水、服务端组件和渐进式加载：它们不是倒退到传统多页应用，而是在修复纯 SPA 对 Web 渐进模型的偏离。

## 核心内容 / 成立机制

SPA 的问题在于，它容易把内容、数据获取和交互能力都绑定到一个大型前端运行时上。这样会带来白屏、SEO、首屏性能、弱网体验和错误恢复问题。

现代框架的回归体现在：

- **SSR / SSG**：先交付可阅读、可索引的内容。
- **流式 SSR**：内容可以分块抵达，而不是等待全部完成。
- **选择性注水**：不是整页一次性激活，而是按优先级激活交互区域。
- **React Server Components**：把部分组件计算留在服务端，让客户端只接收必要结果和交互边界。

这些机制都在恢复“先核心内容，再增强交互”的 Web 原生节奏。
