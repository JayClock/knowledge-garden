# Agent Harness 的双层循环

> [!abstract] 核心观点
> Agent Harness 将整体任务的分解、追踪和改进交给外层 PDCA，将具体任务执行中的质量控制与自我修正交给内层 Steering Loop。

外层循环采用 Plan–Do–Check–Act，负责把整体任务拆成可执行步骤、追踪当前进度，并根据结果调整后续计划。内层循环采用 Feedforward–Action–Feedback–Steer，负责在一个具体任务中提供指引、执行行动、检查结果并继续调整。

如果自动测试发现 Agent 输出不合格，测试属于 Feedback；让 Agent 根据测试结果重写则属于 Steer。Feedback 产生纠偏所需的信号，Steer 才真正根据这个信号改变执行。

两个循环不是人与 Agent 的绝对分工。外层保留人类的高层决策权，但规则明确且已经授权的计划调整可以由 Agent 自动执行，人不必成为每次更新的执行者。
