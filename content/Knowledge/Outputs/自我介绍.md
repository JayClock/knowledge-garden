# 自我介绍

面试官你好，我有 5 年多开发经验，定位是全栈偏前端的平台工程师，前端基本盘是 React 和 TypeScript，后端主要使用 NestJS、PostgreSQL 和 Prisma。相比覆盖更多技术栈，我更关注沿软件交付的知识流理解上下游：从业务模型和契约中消费上游语义，也让自己的产物为下游验收和运行反馈提供证据。

这条主线最早来自低代码平台的多端一致性问题。PC 和移动端曾经重复维护状态、权限和动作规则，我先设计 HATEOAS TypeScript SDK，随后继续参与业务／领域建模和 RESTful API 设计，形成“模型—资源动作契约—SDK—多端客户端”的消费链路。

在 AI Flow 项目中，我把工作流模型转成统一协议、React Flow 编辑器和 TypeScript 执行引擎，并直接编写 PostgreSQL / Prisma 数据模型与持久化代码。为了让验收和运行诊断能够判断用户在哪个环节失败，我还接入监控 SDK，对工作流校验、测试运行和发布增加自定义事件，再通过 executionId 关联前端操作与节点执行日志。

我也直接实现过多人协同平台的 NestJS WebSocket 服务和 PostgreSQL 持久化，并通过单元测试、契约测试、E2E 和人工审核验证交付结果。我的优势不是简单地前后端都做过，而是能理解上下游意图，并把它们转化为可消费、可验证的工程交付。
