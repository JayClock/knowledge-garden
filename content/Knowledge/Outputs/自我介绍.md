# 自我介绍

面试官你好，我有 5 年以上软件开发经验，求职定位是全栈平台与 AI 工程化。我的基本盘一直是 React、TypeScript 和复杂前端平台；我理解的全栈不是弱化前端优势，而是能够从客户端问题继续追到资源契约、业务模型、执行系统和运行反馈。

这条能力主线起点是上海易校的多端一致性问题。当时 PC Web 与移动 Web 会根据 `status / role / permission` 重复维护应用、表单、工作流和导航规则。我先设计 HATEOAS TypeScript SDK，让各端消费服务端 `_links / _templates` 返回的同一套 relation 和 action 契约。落地过程中我进一步认识到，HATEOAS 只有建立在清晰的资源边界、生命周期和接口语义上才稳定，因此继续把能力向上游扩展到四色建模和 RESTful API 设计。

后续我把这条思路继续落到可执行和可协作的平台中：低代码工作流把模型转成 Schema、DAG、变量协议和执行器；上海鼎歆的多人实时协同建模平台则让业务、产品和研发共同维护模型。我独立完成 React Flow 画布、Yjs 数据绑定、Awareness、NestJS WebSocket 协同服务和 PostgreSQL 持久化，并解决 React Flow 与 Yjs 双向绑定回环。在库销存 Agent 案例中，我使用 8X Flow 建立采购履约审计模型，由 AI 基于发布模型生成 OpenAPI 草稿和测试数据，OpenAPI 经人工审核后用于下游代码生成。

此前我还建设过公式编辑器、类 Figma AI 设计工具和全链路监控 SDK。这些经历共同体现的是：以复杂前端为基本盘，向上游理解模型和契约，向下游控制执行、测试和反馈，并用结构化协议、人工审核与质量门禁约束 AI 输出。
